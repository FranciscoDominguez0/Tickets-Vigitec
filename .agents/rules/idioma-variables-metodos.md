# Idioma en el Código

En este proyecto, se deben seguir las siguientes reglas de nomenclatura:

- **Variables, Métodos y Funciones**: Deben nombrarse en **español** (por ejemplo: `$usuario`, `obtenerTickets()`, `crearTicket()`).
- **Nombres de Archivos y Clases**: Deben mantenerse en **inglés** (por ejemplo: `TicketController.php`, `class TicketController`, `User.php`, `class User`).

**Excepciones**:
- Los métodos y convenciones estructurales obligatorias del framework (ej: `index()`, `store()`, `update()`, `destroy()`, `boot()`) se mantienen en inglés.
- Las variables reservadas u obligatorias por el framework (ej. `$request`).
